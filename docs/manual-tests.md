# 수동 테스트 목록

자동 시험(스크립트)으로 확인할 수 없어서 **사람이 직접 확인해야 하는 항목**이다.
확인하면 상태를 `통과` / `실패`로 바꾸고 날짜와 메모를 적는다.

## 시험 방법

실제 데이터와 자동 시작을 건드리지 않도록 시험용 폴더로 실행한다. 자리 비움 기준은 30초로 줄인다.

```powershell
.\build.ps1
Start-Process .\bin\UsageTracker.exe -ArgumentList "--data=`"$PWD\testdata`" --tick=10 --flush=15 --idle=30"
```

끝나면 트레이 메뉴 → 종료 후 기록을 확인한다.

```powershell
.\tools\show-sessions.ps1
```

## 기록 모드 (v0.2.x)

| ID | 항목 | 방법 | 기대 결과 | 상태 |
| --- | --- | --- | --- | --- |
| M1 | 소리 재생 예외 | Chrome에서 영상을 소리 켜고 재생, 맨 앞에 둔 채 50초 이상 손 떼기 | 입력이 없어도 Chrome 활성 시간이 끊기지 않음 | 미확인 |
| M2 | 전체 화면 예외 | 소리 없이 전체 화면(F11) 상태로 50초 이상 손 떼기 | 활성 시간이 끊기지 않음 | 미확인 |
| M3 | 일시정지 중 활성 시간 | 앱을 쓰다가 트레이 → 기록 일시정지 → 15분, 30초 뒤 기록 다시 시작 | 그동안 활성·실행 시간이 끊기고 PC 사용 시간은 계속 | 미확인 |
| M4 | 트레이 메뉴 화면 | 트레이 아이콘 오른쪽 클릭, 마우스 올리기 | 메뉴·하위 메뉴가 정상 표시, 툴팁에 "기록 중: 앱 이름" | 미확인 |
| M5 | 실제 절전·복귀 | 시작 → 전원 → 절전, 1분 뒤 깨우기 | 절전 동안 모든 기록이 끊기고 깨운 뒤 바로 다시 시작 | 미확인 |
| M6 | 로그인 시 자동 시작 | 실제 모드로 한 번 실행 후 로그아웃·로그인(또는 재부팅) | 트레이에 자동으로 나타남 | 미확인 |
| M7 | 탐색기 재시작 | 작업 관리자 → Windows 탐색기 → 다시 시작 | 트레이 아이콘이 다시 나타남 | 미확인 |
| M8 | 원격 데스크톱 | 다른 PC에서 원격 접속 후 연결 끊기 | 끊긴 동안 활성·실행·사용 시간이 끊김 | 미확인 |
| M9 | UWP 앱 | 계산기, 설정 앱 사용 | 실제 앱 이름(계산기 등)으로 활성 시간 기록 | 미확인 |
| M10 | 관리자 권한 앱 | 작업 관리자를 맨 앞에 두고 사용 | 작업 관리자 이름으로 활성 시간 기록 | 미확인 |
| M11 | 24시간 연속 실행 | 실제 모드로 하루 이상 사용 | 메모리 6MB 이하, CPU 평균 0.1% 미만, 오류 없음 | 미확인 |
